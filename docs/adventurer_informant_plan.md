# シナリオゲーム企画書

## タイトル案
**『情報屋、あと七日で閉店』**

## 想定
- ジャンル: 経営シナリオADV（ノベル＋選択式マネジメント）
- プラットフォーム: スマホ（縦持ち想定）
- 想定プレイ時間: 30分
- エンディング数: 4（END1 / END2 / END3 / END4）
- 登場人物方針: **冒険者ギルド公認の情報屋ネットワーク関係者のみ**

## コンセプト
「戦わず、潰さず、先に信頼を取る」。

主人公は**冒険者ギルド公認の情報屋を管理する立場**。
一週間後、圧倒的な情報量を掲げる新店舗が開店予定で、既存店の売上は激減寸前。
プレイヤーは7日間の意思決定で、価格競争・信頼構築・仕入れ改善を行い、
**生活を守るために経営を安定化**させる。

## 主人公と主要キャラクター

### 主人公
- 名前: リオ（変更可）
- 立場: 冒険者ギルド公認「情報屋管理人」
- 特徴: 記録管理と交渉が得意。戦闘力は低い
- 目的: 新店舗オープン前後の売上崩壊を防ぎ、生活基盤を守る

### 主要キャラ（全員、冒険者ギルド公認圏）
1. **アスター**（前衛冒険者）
   - 現場の一次情報に強い。報酬単価に厳しい
2. **リノ**（斥候冒険者）
   - 速報性の高い情報を持つ。信用重視
3. **バルグ**（ベテラン冒険者）
   - 固定客を多く抱える。店の評判に影響力が大きい
4. **ノクト**（新規オープン予定店の責任者）
   - 情報量と広告力で市場を奪いにくる競合

## 30分構成（目安）

1. **DAY 1：危機発覚（5分）**
   - 「一週間後に大型情報屋が開店」の通達
   - 現在の資金・顧客・在庫（情報ストック）を確認

2. **DAY 2-3：方針決定（8分）**
   - 3方針から2つを選択
     - 価格を下げて回転率を上げる
     - 冒険者と独占契約して情報の質を上げる
     - 初心者向け相談窓口を作って固定客を増やす
   - 選択で中盤の交渉難易度と顧客反応が変化

3. **DAY 4：競合分析（5分）**
   - ノクトの新店は「量は多いが精査が甘い」弱点が判明
   - 主人公側は「精度」「アフター対応」で差別化可能とわかる

4. **DAY 5-6：最終調整（7分）**
   - 「値付け再設定」「冒険者への歩合調整」「看板サービス決定」から選択
   - 最終日に使える切り札（信用/品質保証/顧客基盤）が変化

5. **DAY 7：開店当日対決（5分）**
   - 競合オープン当日の集客戦
   - 「何を売りにするか」「どの客層を守るか」を最終選択

## 分岐設計（シンプル）

### フラグ
- `cost_control`（コスト管理の成功）
- `trust_network`（冒険者ネットワークの信頼）
- `premium_service`（高付加価値サービスの確立）

### エンディング条件
- **END1「倒産」**
  - 到達条件: END2 / END3 条件を満たさず、一週間後を迎える
  - 結果: 競合オープン後に資金繰りが破綻し、店を畳む

- **END2「買収」**
  - 到達条件: 資金を十分に貯め、一週間後の競合オープン前に買収を実行
  - 結果: 競合を取り込み、情報網と顧客基盤を一気に拡大

- **END3「資産」**
  - 到達条件: END2（買収）以外の方法で進行し、資金使用回数が3回以下
  - 結果: 支出を抑えて純資産を残し、独立経営として生存

- **END4「未実装（今後追加予定）」**
  - 到達条件: まだ作る予定
  - 結果: まだ作る予定

## スマホ向けUI/演出方針

- 1タップで進行、選択肢は最大3つ
- 1画面の文章は短め（2〜4行）
- 経営指標（資金/信用/固定客）を常時ミニ表示
- オート/スキップ/バックログを常設
- DAY切替時にオートセーブ

## 実装しやすいシーン素材（最小）

- 背景: 4枚（情報屋カウンター、掲示板前、路地、競合店前）
- 立ち絵: 4人×2表情
- BGM: 3曲（日常/焦り/逆転）
- SE: 8種程度（紙、通知、硬貨、足音、ざわめき等）
- UI: 経営ゲージ3種（資金/信用/固定客）

## 冒頭サンプル（そのまま使える台本）

> リオ「……一週間後、向かいに新しい情報屋？」  
> バルグ「噂じゃ情報量は三倍だ。正面から潰し合えば、先に息切れするのはお前の店だ」  
> リノ「でも、量だけなら勝てる。精度と責任まで含めたら、まだ勝負できるよ」  
> リオ「生活を守る。七日で、店の価値を作り直す」

### 最初の選択肢
1. 値下げキャンペーンを始める（短期売上重視）
2. 冒険者との独占契約を進める（品質重視）
3. 初心者相談パックを作る（固定客重視）
